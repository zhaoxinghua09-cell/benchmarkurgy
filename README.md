# Benchmarkurgy · 基准工程术

> 主张：基准创造有治理——目标定义 → 难度校准 → 防污染 → 负对照 → 版本治理 → 退役
> 家族：LGD 创造术元层（-urgy）｜ 状态：占位声明（查重全维度 0 占用，R1+R2）

## 定义
创造 AI 评测基准的方法论：基准是"检查的检查的检查"（测定测量者）。基准适用三律——有籍（基准注册与版本）、有证（基准能失败：负对照）、有门禁（发布与退役受控）。

## 生命周期
目标定义 → 难度校准 → 防污染（训练集去重/时间戳）→ 负对照（基准必须能被"假系统"失败）→ 版本治理 → 退役（失效基准显式退役）。

## 与"benchmark engineering"的区隔
benchmark engineering（工程视角：怎么做基准）已存在；Benchmarkurgy 是治理视角——基准本身的籍、证、门禁与退役纪律。
